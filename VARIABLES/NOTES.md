SO VARIABLES IN JS HAVE SAME WORKING COMPARED TO OTHER PROGRAMMING LANGUAGE LIKE C, C++, PYTHON ETC...

BUT IN JS WE HAVE 3 TYPES OF VARIABLES
1. var
2. let
3. const

1. var is old style form of declaring variables 
2. let is modern style of declaring variables
3. const is used when an data has to stored permanently or something that will remain same

*
VARIABLE NAME CAN HAVE LETTERS , NUMBERS, $ AND _ 
VARIABLE NAME CANNOT BE STARTED WITH A NUMBER
VARIABLES ARE CASE SENSITIVE
*

*
CAPITAL LETTER CONST ARE USED WHEN WE HAVE TO STORE CONSTANTS THAT ARE HARD CODED OR KNOWN PRIOR TO EXECUTION
NORMAL CONST WIHTOUT CAPITAL LETTER ARE STORED AT RUN TIME
