alert , prompt and confirm are function used to interact with user.

it pops up a mini window called modal window. 
modal here means it restricts interaction with rest of web page until the popped window is dismissed.

alert is used to pop mini window with a message and user has to press ok or cancel or esc to proceed interaction with rest of web page

prompt is used to take input from user and return for further use if user. 
two parameters has to be set in prompt one with message above input box and other is optional parameter to be default value inside input box if user press ok the input is store or user press cancel or esc null is stored
*it is must to have a optional parameter as internet explorer takes undefined input if pressed esc or cancel without having optional parameter in prompt*

confirm is used to display question if user press ok it takes true as input and if press cancel or esc it takes false as input
