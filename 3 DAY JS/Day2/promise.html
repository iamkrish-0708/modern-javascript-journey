` Promise In JavaScript

JS IS SINGLE THREAD ( IT EXECUTES SINGLE THING AT A TIME). IN CASE WHERE API REQUEST FROM FRONTENT GOES TO BACKEND REQUESTING SOME DATA IF IT TAKES 2 SEC OF TIME WE CAN'T KEEP BROWSER WEB PAGE FREEZE TILL THEN. PROMISE IN JS IS OBJECT REPRESENTING OF EVENTUAL COMPLETION OR FAILURE OF ASYNCHRONOUS OPERATION. A PROMISE CAN BE IN 3 STATES: 1.FULFILLED: OPERATION SUCCEEDED. 2.PENDING: OPERATION ONGOING. 3.REJECTED: OPERATION FAILED. PROMISE IS HELPFUL FOR AVOIDING CRASHING OF WEB PAGES BY INTEGRATING IT WITH TRY,CATCH AND FINNALLY(ERROR HANDLING).
