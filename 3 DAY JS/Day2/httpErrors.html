when we fetch inside async function and if the request lead to non existent thing so fetch return promise fulfilled instead direct jump execution onto catch block. hence fetch fails to detect the http errors like 404 not found. solution to this we use response.ok which is true for status codes 200-299, and false for 404, 500, etc. response.status is used to determine HTTP status code number like 404 ,200 , 401 , etc. so in real react application without this our program can destructure objects/arrays of non existent thing.
