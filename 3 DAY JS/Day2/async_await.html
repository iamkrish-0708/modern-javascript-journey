async/await COMES AS SOLUTION FOR PROMISE CHAINING WHICH LEADS TO PROMISE HELL/NESTED CALLBACK CLUTTER WHICH FAILS CODE BEING ASYNCHRONOUS. async IS USED BEFORE FUNCTION DECLARATION AND IT TELLS THE FUNCTION WILL PERFORM ASYNCHRONOUS WORK & WILL ALWAYS RETURN A PROMISE await KEYWORD IS USED INSIDE async FUNCTION . IT PAUSES THE FUNCTION EXECUTION AT THAT LINE UNTIL PROMISE IS RESOLVED AND GIVING YOU UNPACKED DATA DIRECTLY. try..catch BLOCK REPLACE .catch(). IF ANY await FAILS EXECUTION DIRECTLY JUMPS TO catch BLOCK.

// NOTE : WHEN UNPACKING ARRAY USE [] AND FOR OBJECT UNPACKING USE {}.
