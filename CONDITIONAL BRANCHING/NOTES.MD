CONDITIONAL BRANCHING IS USED WHEN HAVE TO PERFORM CERTAIN TASK WHEN SPECIFIC CONDITIONS ARE MET

TYPES:
*1*
if(condition){
    alert("hello")
}

// HERE, MESSAGE INSIDE alert WILL BE SHOWN ONLY IF condition IS TRUE.

*2*
if(condition){
    alert("hello")
}
else{
    alert("Bye")
}

// HERE , EVEN IF condition IS TRUE THEN hello WILL BE SHOWN AND IF condition IS FALSE THEN Bye WILL BE SHOWN

*3*
if(condition){
    alert("hello")
}
else if(condition){
    alert("Hey")
}
else{
    alert("Bye")
}
// HERE FIRST IF BLOCK GETS TRUE THEN REST OF BRANCH WILL BE IGNORED BUT WHEN FALSE THEN IT WILL MOVE TO else if AGAIN WILL CHECK IF CONDITION IS TRUE AND WILL SHOW Hey IF TRUE OR WHEN FALSE THEN else BLOCK WILL BE EXECUTED

CONDITIONAL OPERATOR ?
IT IS COMPACT FORM IF ELSE STATEMENT
SYNTAX- if (condition)?true:false
EX- if(age>18)?"adult":"kid"; 
HERE FOR TRUE CONDITION adult WILL BE RETURNED AND FOR FALSE CONDITION kid WILL BE RETURNED

MULTIPLE ?
EX-
alert((salaryExpectation<1500)? "HUH! YOU SHOULD BE MORE OPTIMISTIC":
        (salaryExpectation<50000)? "HMMMM.. THAT'S SOUNDS REALISTIC!":
        (salaryExpectation>50000)? "AAHH! IT IS GOOD THAT YOU HAVE BIG DREAMS!":"")

HERE , THE ONLY DIFFERENCE TO PRIOR EXAMPLE IS THAT OVER HERE CONDITIONS ARE CHECKED MULTIPLE TIMES AND ONLY MOVES TO NEXT CONDITIONS IF IT CURRENT ONE IS NOT MET
